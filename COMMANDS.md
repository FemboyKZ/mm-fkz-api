# FKZ API Commands

| Chat         | Console          | Default flag | Description                                 |
| ------------ | ---------------- | ------------ | ------------------------------------------- |
| `!crosschat` | -                | open         | Hide or show cross-server chat for yourself |
| -            | `mm_fkz_reload`  | console only | Reload `core.cfg` without a map change      |
| -            | `mm_fkz_version` | console only | Print the plugin and interface versions     |
